CS3 Bridge

Problem Formulation

Problem-solving agents convert a real-world story into a searchable state space. This is the step that makes BFS, A*, hill climbing, or GA meaningful.

1

State Space

All configurations the problem can be in. In 8-puzzle, every tile arrangement is a state.

2

Initial State

The state from which the agent starts. This is the first node in the search tree or graph.

3

Actions

Legal moves from a state. For a graph, actions are outgoing edges; for 8-puzzle, blank-tile moves.

4

Transition Model

The result of applying an action: Result(state, action) gives the successor state.

5

Goal Test

A check for whether the current state satisfies what the agent wants.

6

Path Cost

The cost accumulated along a path. UCS and A* depend on this directly.

CS4 + A* Webinar

Heuristic Design Studio

Heuristics are educated estimates. They guide informed search, but A* only keeps its guarantee when the estimate is disciplined.

Both h1 and h2 are admissible for the standard 8-puzzle. h2 is usually more informative because it counts how far each tile must move.

A* Conditions

Admissibility says do not overestimate. Consistency says each edge obeys a triangle-inequality style rule.

Evaluation

f(n) = g(n) + h(n)

g(n) is the path cost already paid. h(n) estimates the remaining cost.

Admissible

0 <= h(n) <= h*(n)

The heuristic is optimistic: it never claims the goal is farther than it truly is.

Consistent

h(n) <= c(n,a,n') + h(n')

Moving one step plus the new estimate cannot be cheaper than staying with the old estimate.

Local Search, Beam Search, Genetic Search, and ACO

Here the path often does not matter. The current state itself is the candidate solution, so the algorithm keeps improving configurations.

Revision Plan

How to Study This Module

Use the teacher's ordering first, then deepen with the references. Keep solving small examples by hand.

1. Memorize the skeleton

Agent -> PEAS -> environment type -> problem formulation -> algorithm choice -> guarantee check.

2. Practice the tables

For BFS, DFS, UCS, IDS, Greedy, and A*, compare completeness, optimality, time, space, and required assumptions.

3. Work examples slowly

For graph search, write frontier and explored after each expansion. For A*, write g, h, and f.

4. Separate global and local search

If the path matters, use tree/graph search. If only the final configuration matters, think local search or population search.
